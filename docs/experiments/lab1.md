# Первые пробы: ЛР1

Статус: протокол подготовлен, запуск LLM ещё не проводился. Результаты не
подменяются синтетическим ответом модели.

## Вопрос эксперимента

Может ли прямой промпт преобразовать короткий багрепорт в проверяемый сценарий
регрессионного теста, сохранив входные данные, ожидаемый результат и указав
неопределённость вместо выдумывания деталей?

## План пробы

1. Взять синтетический пример `seed-01` из
   [чернового набора](../quality/golden-dataset.jsonl).
2. Передать модели только требование и явно заданный контекст; не давать доступ к
   репозиторию или командам.
3. Попросить вернуть JSON: проверяемые условия, сценарии, входы, ожидаемые
   результаты, неизвестные детали и риски.
4. Повторить запрос трижды с фиксированной версией промпта и параметрами.
5. Вручную оценить формат, соответствие задаче, воспроизводимость и отсутствие
   неподтверждённых предположений. Записать модель, версию, дату и стоимость.

## Предварительный вывод

Пока нет экспериментальных данных и нельзя утверждать, что прямой промпт работает.
Первое решение для проверки — direct prompting как минимальный baseline; выбор
зафиксирован как предварительный в [ресёрче](../research.md). Для настоящего
прогона нужны одобренный провайдер/локальная машина, актуальный тариф и решение
команды о допустимости данных.
