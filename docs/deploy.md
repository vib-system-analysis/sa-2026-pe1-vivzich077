# Развёртывание

## Локальная заглушка

```sh
cp .env.example .env
docker compose -f compose.dev.yml up --build
```

Сервис доступен по адресу `http://localhost:8000`; проверка состояния —
`http://localhost:8000/health`. Остановка: `docker compose -f compose.dev.yml down`.

## Публичный стенд

Статус: не развёрнут. Публичный URL появится после того, как команда выберет
хостинг и владелец инфраструктуры предоставит доступы. Не указывать локальный
адрес или URL документации как production URL. До публичного развёртывания пункт
Hello-world в DoD остаётся невыполненным.
