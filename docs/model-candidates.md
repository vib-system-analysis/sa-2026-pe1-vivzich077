# Кандидаты моделей и токен-бюджет

Статус: сравнение для планирования, не результат бенчмарка. API-ключей и
результатов реальных вызовов пока нет. Не передавать реальные данные до проверки
условий провайдера и согласия команды.

## Кандидаты

| Кандидат | Тип | Почему рассматриваем | Цена и ограничения |
| --- | --- | --- | --- |
| GPT-6 Luna | Облачная API-модель | Удобный платный baseline с опубликованными тарифами | На странице тарифов при проверке: стандартный режим, короткий контекст — $0.10 за 1 млн входных и $0.50 за 1 млн выходных токенов. Проверить актуальность и доступность API перед запуском. |
| YandexGPT Pro | Облачная российская модель | Кандидат для проверки доступности в российском контуре и альтернативы внешнему API | Тариф не удалось надёжно извлечь из открытой страницы в текущем окружении. Проверить актуальную цену, доступный регион и условия хранения данных в консоли до эксперимента. |
| Qwen3-8B | Локальная open-weight модель | Apache-2.0; карточка модели указывает 8,2B параметров и 32 768 токенов контекста | Нет тарифа за токены. Стоимость считать по времени GPU/CPU, инфраструктуре и электричеству; аппаратный профиль пока не измерен. |

Источники: [OpenAI pricing](https://platform.openai.com/docs/pricing),
[Yandex Foundation Models pricing](https://yandex.cloud/ru/docs/foundation-models/pricing),
[Qwen3-8B model card](https://huggingface.co/Qwen/Qwen3-8B).

## Оценка одного сценария

Предварительный бюджет одного запроса: 8 000 входных токенов (задача, системные
ограничения и небольшой разрешённый контекст кода) и до 2 000 выходных токенов
(условия, сценарии и черновик теста). Это проектное допущение, а не результат
счётчика токенов; заменить фактическими измерениями на примерах.

Для GPT-6 Luna, короткий контекст, стандартный тариф из указанной страницы:

```text
8 000 × $0.10 / 1 000 000 + 2 000 × $0.50 / 1 000 000 = $0.0018
```

Оценка не включает повторные вызовы, инструменты, налоги и изменения тарифа.
Предел $0.10 из [PRD](prd.md) является предварительной командной гипотезой и
оставляет запас для нескольких попыток; сравнить с фактическим расходом API.

Для YandexGPT использовать ту же формулу с актуальными тарифами в валюте
провайдера. Для Qwen3-8B измерить длительность одного запуска на целевом железе и
умножить на стоимость часа; до выбора оборудования числовая оценка неизвестна.

## План сравнения

На одном и том же версионируемом наборе измерить: форматную валидность ответа,
корректность тестового сценария по ревью, успешность компиляции/запуска,
выявление исходного дефекта, латентность p50/p95 и цену запроса. До получения
наблюдений ни один кандидат не объявляется победителем.
