# Лабораторная работа 4

Воспроизводимый анализ графа целевой архитектуры Test Writer.

## Запуск

```bash
python -m pip install -r requirements.txt
python analyze.py
```

Скрипт читает `nodes.csv`, `adjacency.csv` и `edges.csv`, проверяет, что
матрица смежности соответствует типизированным рёбрам, рассчитывает метрики и
обновляет `results.txt` и `graph.svg`.
